# ТПМ-2 — тенгварская пишущая машинка на челноке Хаммонда, редакция 0.14

Полный комплект проекта: исходники документа и модели, собранная модель (STL, рендеры, сборочные листы), интерактивная страница и проектный документ.

## Сборка

Нужны python 3 с `manifold3d`, `shapely`, `numpy`, `scipy`, `trimesh`, `python-fcl`, `fonttools`, `matplotlib`, `pillow`, `scikit-image`, `numba`, `rtree` (лучи проверки чтения, с 0.10), `uharfbuzz` (оси шрифтов без якорей, с 0.11) и XeLaTeX. Только чтобы заново снять надпись и герб корпуса (с 0.12; готовые `data/inscription.json` и `data/device/device_regions.json` лежат в архиве): node, `rsvg-convert`, `opencv-python`.

```
python3 -I tools/model/build.py gen/model gen   # модель, STL, проверки (около 30 минут)
make fonts                                       # наборы шрифтов: блоки, гребёнки, проверки (22 набора, около 50 минут)
make                                             # таблицы, страница, PDF
make web-plain                                   # по требованию: страница с неупакованной геометрией (для сверки)
make web-single                                  # по требованию: страница одним файлом
make pack                                        # архив ../tpm2-0.14-full.zip с проверкой имён файлов
```

`make` пересобирает модель, если какой-нибудь файл в `tools/model/` новее `gen/model/model.json` (с 0.11 `data.py` больше ничего не пишет, и лишних пересборок нет). Набор другого шрифта: `TPM_FONT=<id> python3 -I tools/model/fontset.py gen/fonts`.
Физические проверки (с 0.13; нужны ещё `mujoco`, `rtree`): `make physics` — снимок положений около 6 мин, ступень 1 около 8 мин, узлы ступени 2 около 10 мин. Детали модели они не меняют; быстрая проверка пересечений выбранных деталей — `python3 -I tools/physics/quickcheck.py ИМЯ...`.

Сверка страницы с моделью (нужны playwright с chromium и three.js r128 локально):

```
python3 tools/web/compare_model.py gen/web-plain/tpm2-model.html THREE_MIN_JS ORBIT_CONTROLS_JS
```

## Состояние на 0.14

Дополнение к 0.14:
- две точки у lambe и alda — свой знак в чаше lambe (`mark:ddotbL`, Shift + «0»), как черта удвоения; у шрифтов без своей черты для lambe в чашу переносится и она (`tools/glyphvar.py`: синтетические глифы `<знак>.inlambe`);
- набор Tengwar Elfica (Enrique Mombello, раскладка Дэна Смита); у Tengwar Telcontar с техт убран пунктирный кружок;
- узел H: пружины без чисел посчитаны по ходу, массе и отпущенному времени; пружина клина фиксатора ряда, щёчки направляющей бумаги до обода торцевых стенок;
- страница: наборы шрифтов в `gen/web/fonts/`, в архиве только упакованная страница;
- физические проверки, ступень 2б (`tools/physics/shaft.py`, `stage2b.py`, `stage2b_variants.py`, `stage2b_package.py`; `make physics`): узлы на настоящем законе циклового вала. На конце завода вал встаёт на взводе, крыльчатка регулятора не держит скорость на полном заводе; решение автора внесено в модель (журнал, заходы 6–7): тормоз регулятора граммофонного типа (`parts.governor_brake`, `params.GOV_*`), момент в конце завода `params.TAU_END` = 39,4 мН·м (`motor.py`), шептало 158° (`CYCLE['strike']`), пружины каретки 7 Н, ленты 16 Н, толкателя взвода 3 Н, щупов 1,00/0,75/0,78 Н с наконечниками, накладки упора полей; ступени 1, 2 и 2б повторены. Запас завода — около 480 знаков (было 780); как его вернуть — документ, «Пружина и передача»; `stage2b_variants.py` и `stage2b_package.py` — запись решения, собираются по требованию;
- клавиши: шток 3×4 мм опущен до рычага и идёт в гребёнке на всём ходе, шип в пазу рычага, буртик с прокладкой — упор покоя; возвратные пружины 0,34 Н — под рычагами на планке (`parts.key_return`, `params.KRS_*`); прежний шток на стойке над гребёнкой был перевёрнутым маятником (журнал, заход 4);
- архив распаковывается на Android: имена файлов кэша `gen/model_cache` больше не различаются одним регистром (заглавная буква → `^буква`, не-ASCII → `~hhhh`), архив пишет `make pack` (`tools/pack.py`) и перед записью проверяет имена.

- по итогам физических проверок 0.13 модель изменена (решения автора: «как надёжнее и оптимальнее для работы машинки»):
  - толкатели поворота и подъёма ведутся кулачками в обе стороны: обратные кулачки, коромысла на стойках, обратные толкатели с подпружиненными роликами (`parts.RET`, `ret_*`);
  - держатель челнока на кольце подъёма; замкнутая лента поворота с роликом и натяжителем 10 Н;
  - молоток летит один: пружина между рычагом взвода и молотком, шептало, губа рычага возвращает молоток (`parts.HAM_*`, `sear_beta`); новые профили `cock` и `strike`;
  - подача каретки с 200° (`params.CYCLE`), собачка Д опускается в 325°, пружина каретки постоянной силы 2 Н, накладка на пальце U;
  - тяги спуска — углепластиковые прутки, пружина щупа W 1,5 Н, возвратные пружины клавиш 0,2 Н;
  - опоры и крепёж (`tools/model/supports.py`): основание из фанеры 4 мм, брус гребёнок, стойки качалки спуска и защёлки цикла, подвес направляющей толкателей, мостик упора нуля M, щёчки направляющей и кронштейны подставки бумаги, стопорные кольца; квадратные штоки у клавиш со смещённым колпачком;
  - момент инерции вала в `motor.py` — по сеткам;
- физические проверки повторены на новой модели (раздел «Физические проверки», журнал — заход 2).
